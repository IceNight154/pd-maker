# PDMaker 10차 — ARK_PD 저장소 기반 데이터 정합성 · 편집 기능

브랜치는 `claude/modest-rubin-k9akxp`입니다. 커밋 해시는 §9 에 적었습니다.

이번 차수의 기준은 하나입니다. **선택한 게임 저장소가 진실의 원천이다.** 파생 프로젝트의 데이터를 SPD 이름 · 분류 · 경로 · 구조로 바꿔 끼우지 않습니다. 저장소에서 읽은 값, 추론한 값, 사용자가 고친 값, PDMaker 기본값을 칸마다 구분해서 저장합니다.

대상 저장소는 두 개입니다.
- `game/ARK_PD-main`: RogueNights 0.5.4, 프로파일 `83769a3c65f1`
- `game/shattered-pixel-dungeon-master`: 기준 SPD, 프로파일 `64f9cc156eaa`

BA 저장소는 9차 호환 테스트(`repo-compat`)로 회귀만 확인했습니다.

## 2. 구조 · 바뀐 파일

**공용 파서 `editor/renderer/js/javasrc.js`.** 노드 분석기와 편집기가 같이 씁니다.
- 맵: `levelSlots`(newLevel → 깊이 · 갈래 · 조건 · 보스 깊이), `levelTransitions`, `staticLayout`(`build()` 의 `setSize` · `Arrays.fill` · `Painter.fill` · `map[n]=` 재현), `terrain`
- 영웅 스킨: `heroSkins`
- 업적: `badges`(대소문자 섞인 id, 키 한 개 / title·desc, 들여쓰기와 무관한 조건 메서드 찾기, 시트 격자)
- 타이틀: `titleScene` · `bannerRects`
- 기록: `statistics`

**`editor/repo-analyzer.js`(VERSION 3).**
- 영웅에 `id / nameKey / nameSource / aliases / spriteKind`
- `maps`(슬롯 · 생성 방식 `procedural/fixed/fixed-partial/code` · 고정 타일 · 연결 · 안 쓰는 층)
- 몬스터 `spriteKind`(direct / inherited / dynamic / none) · `properties` · `loot`
- `badges` · `title` · `profile`(저장소 지문)
- **분류.** 근거마다 가중치를 둡니다: `boss-property` · `miniboss` · `boss-health-bar` · `boss-level-spawn` · 패키지 · 이름 · `npc-class`. 그 합으로 boss / elite / mob / npc / review 와 신뢰도를 정합니다.
  - 후처리 `summon-of`: 보스 안에 중첩된 소환물 클래스가 스스로 BOSS 를 갖지 않으면 몬스터로 봅니다.
  - 이름만 보스 같은 것은 보스로 올리지 않습니다.

**새 편집기 모듈.**
- `provenance.js`: 칸 출처 기록 · 다시 맞추기 규칙 · 출처 상자
- `reposync.js`: 저장소 → 프로젝트 맞추기 계획 · 적용 · 확인 창. 예전 `gameSyncVanilla` 를 대체합니다.
- `repomaps.js`: 저장소 맵 목록 · 자세히 · 그래프로 가져오기 · `game` 노드 페이지

**편집기 수정.**
- `schema.js`: 캐릭터 종류에 `elite`(엘리트 · 미니보스) · `unsorted`(분류 확인 필요) 추가, `PDM.isHostile`, 맵 방식 `game`(게임 원래 맵), `heroClasses / heroClassName` 를 저장소 기준으로 바꿈
- `hero.js` · `character.js`: 출처 상자
- `map.js` · `world.js`: `game` 노드 · 추정 연결 점선
- `badges.js`: 저장소 격자 · 키 형식
- `title.js` · `titlemodel.js` · `titlepreview.js`: 원래 타이틀 구조 상자 · 저장소 모드 미리보기
- `gamescan.js`: 분석 실패 시 `REPO_ANALYSIS = null`
- `app.js` · `project.js`: 열 때 · 저장소 바꿀 때 확인 창
- 여섯 편집기의 `['mob','boss'].includes` 를 `isHostile` 로 바꿈

**런타임.**
- `MakerRuntime.createLevel`: `mode: "game"` 노드는 저장소의 층 클래스를 리플렉션으로 만듭니다. 클래스가 없거나 `Level` 이 아니면 로그를 남기고 테마 생성기로 대신합니다.
- `MakerMob`: `elite` 이면 `Property.MINIBOSS` 를 붙입니다.

**설치기 `runtime-installer.js`.** `missingClasses()` 를 추가했습니다. 런타임이 쓰는 게임 클래스가 저장소에 없으면 **파일을 하나도 고치기 전에** 설치를 거부합니다. ARK 는 14개가 없습니다.

## 3. 데이터 출처 · 다시 분석 규칙

리소스마다 `src = { profile, repo, at, fields: { <칸>: { from, v, file, line, key, note, pending } } }` 를 저장합니다.

| 출처 | 뜻 | 화면 표시 |
|---|---|---|
| `repo` | 저장소에서 직접 읽은 값 (번역 글 · 상수 · 리터럴) | 저장소 원본 (초록) |
| `derived` | 저장소에서 추론 (상속 그림 · 분류 점수 · 깊이 순 연결) | 저장소에서 추론 (파랑) |
| `default` | PDMaker 기본값 | PDMaker 기본값 |
| `user` | 지금 값이 기록한 `v` 와 다름 = 사용자가 고침 | 사용자 편집 (노랑) |

다시 분석하거나 맞출 때의 규칙은 다음과 같습니다.
- **사용자가 안 고친 칸**은 새 저장소 값으로 바꿉니다.
- **사용자가 고친 칸**은 그대로 둡니다. 저장소 값까지 바뀌었으면 **충돌**로 보고하고, 새 값을 `pending` 에 둡니다. 사용자는 출처 상자의 "원본 값으로" 버튼으로 고를 수 있습니다.
- **저장소에서 사라진 항목**은 지우지 않습니다. 확인 창에서 체크한 것만 지우고, 기본은 사용자가 안 건드린 것만 체크합니다.
- **ID 충돌**(같은 노드 id 등)은 `_dup` 을 붙여 따로 만들고, 합치지 않습니다.
- **분석 실패**(저장소 없음 · 손상)이면 분석 결과를 비웁니다. 프로젝트 데이터는 바꾸지 않습니다.
- **저장소를 바꾸면** 리소스에 붙은 프로파일 id 가 지금 저장소와 다른 경우 경고하고, 확인 창으로 다시 맞춥니다.
- **분류를 사용자가 지정**하면(`kind` 칸이 `user`) 다시 분석해도 바뀌지 않습니다.

## 8. 남은 위험

1. **이 PC 의 ARK 저장소가 예전 테스트 플레이 설치로 고쳐진 상태입니다.** `.pdmaker-backup` 이 28개, `pdmaker` 패키지 78 파일, `ark-pd/.pdmaker-backup` 이 있습니다. 사용자 승인 없이 게임 저장소를 고치지 않는다는 원칙에 따라 되돌리지 않았습니다. 편집기의 **"런타임 제거"**로 원본 상태로 돌릴 수 있습니다. 앞으로는 설치기가 이런 저장소에 설치하지 않습니다.
2. **런타임이 ARK 와 맞지 않습니다** (클래스 14개 없음). ARK 를 대상으로 한 테스트 플레이는 아직 안 됩니다. 이번 차수는 데이터 정합성 · 편집까지이고, ARK 용 런타임 어댑터는 다음 차수의 일입니다.
3. **타이틀 저장소 모드는 미리보기만 저장소를 따릅니다.** 횃불 입자 · 배경 흐름은 비슷하게 그린 것입니다.
4. **연결 추정.** 원본 연결이 없는 맵은 깊이 순으로 이은 "추정" 연결(점선)입니다. 이벤트 층처럼 조건으로 들어가는 곳은 "미확인"으로 남습니다.
5. **분류 신뢰도 '낮음 / 근거 없음'인 캐릭터**는 "분류 확인 필요"로 둡니다. ARK · 기준 모두 0개였지만, 다른 저장소에서는 생길 수 있습니다.
6. **예전 프로젝트에는 출처 기록이 없습니다.** 그래서 SPD 기본값과 같은 값은 "기본값"으로 보고 바꿉니다. 사용자가 일부러 SPD 값과 똑같이 적어 둔 경우는 구분할 수 없습니다. 확인 창에 바뀌는 항목이 모두 나오므로, 체크를 풀어서 막을 수 있습니다.
