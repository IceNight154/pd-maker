기준: 브랜치 `claude/modest-rubin-k9akxp`. 시작 HEAD `647cab8`(6차 최종 보고 커밋 `9543ac6` 의 후손 — 6차 이후 게임 UI 스킨 수정 1개)이었고, 작업 트리는 깨끗했습니다.
순서: 조사 → 공통 규칙 → 런타임 → 편집기 → 검사 · 자동 테스트 → 문서.

## 1. 타이틀 화면 데이터 구조

`title.json` 의 6차까지 칸은 그대로 두고, 필요한 칸만 더했습니다. **새 칸이 없으면 6차까지와 같은 모습**입니다. 버전 번호를 바꾸지 않았고 변환도 없습니다.

```
title.json
  enabled · music · background · menus · layers[] · logo · gate · version · exit · hideButton · pages   (6차까지 그대로)
  buttons
    layout       game | grid | column | free(새: 버튼마다 place)
    style        기본 바탕 조각 (예전 그대로)
    anim         묶음 등장 · 대기 애니메이션 (예전 그대로)
    states       { normal | hover | focus | pressed | disabled : 상태 모양 }      새: 모든 버튼 (창 안 버튼도)
    items[]      예전 칸 (id · label · visible · icon · action · scene · title · text · url · custom) +
                 enabled · noSave(disable|hide|newgame) · window(창 id) · size(글자 크기) · place{x,y,w,h} ·
                 focusOrder · states{…}(이 버튼만) · effects[]                       새
  elements[]     새: 글 · 그림 요소
                 { id, type: text|image, name, visible, show: always|gate|menu, layer: back|front,
                   text, fallback, size, color, align, w(줄바꿈 폭) | image, scale, angle,
                   x, y(0~1), anchorX, anchorY, offsetX, offsetY, alpha, safe(안전 영역 안), effects[] }
  windows[]      새: 사용자 창 (팝업)
                 { id, title, titleColor, w, h(0 = 내용에 맞춤), padding, offsetX, offsetY, skin | image + slice,
                   closeButton, closeEsc, closeOutside, anim{type: none|fade|slideUp|slideDown, duration},
                   sounds{open, close}, content[] }
                 content[]: text · image · button · divider · space · scroll · setting   (12장의 칸)
```

- 상태 모양 칸: `skin`(chrome.png 조각 이름) · `image` + `slice`(내 9조각 그림) · `textColor` · `textAlpha` · `alpha`(전체) · `scale`(바탕 크기 0.5~2) · `bright`(바탕 밝기 0~3) · `dy`(아래로 px).
- 효과 칸: `trigger`(enter · always · hover · focus · click) · `type`(fade · move · scale · bright · shake) · `dir` · `from` · `to` · `duration` · `delay` · `repeat`(0 = 한 번, −1 = 끝없이) · `yoyo` · `ease`(linear · smooth · inout · back) · `freq`(흔들림).
- 좌표: 게임 UI 좌표(논리 화면). 위치 0~1 = 화면(또는 안전 영역)의 비율, 크기 · 이동 = 게임 픽셀. 화면 크기가 기기마다 다르므로 "기준 해상도"를 두지 않고, 비율 + 픽셀로 놓습니다.
- 배경 크기 맞춤은 6차의 그림 레이어 `fit` 그대로입니다: `cover`(화면 채우기 · 잘림) · `contain`(화면 안에 맞춤) · `none`(원래 크기 × 배율) · `width` · `height`(비율 유지 확대) · `stretch` + `x · y · anchor · offset · scale`(사용자 지정 위치 · 크기). 편집기와 게임의 식이 같습니다.

## 2. 기존 프로젝트 호환성

- **예전 `title.json` 은 그대로 읽습니다.** 열기만 하거나 다른 것을 고쳐 저장해도 `title.json` 은 다시 쓰지 않습니다 (`run.js` · `ui-title.js` 가 바이트 단위로 확인).
- **모르는 칸은 지우지 않습니다.** 편집은 읽은 객체를 고치는 방식이라 다른 칸이 남습니다 (`customX` 로 확인).
- 새 칸이 없으면 6차까지와 같은 배치입니다. 게임에서 확인: 예전 모양 프로젝트의 버튼 8개가 96,129 · 214,129 · 96,158 … 로 같습니다.
- 새 프로젝트의 타이틀은 6차와 같이 꺼진 채(게임 원래 타이틀)로 시작합니다. 새 기능은 편집기 "빠른 시작 → 예시 (요소 · 창 · 효과)"로 볼 수 있습니다.
- **동작이 바뀐 곳 (버그 수정)**:
  - "화면을 누르세요" + 등장 애니메이션 "없음"이면, 예전에는 누르기 전에도 버튼이 보였습니다. 이제 누른 뒤에 보입니다 (편집기 미리보기는 원래 그렇게 그렸음).
  - 타이틀이 PDMaker 가 붙인 표시(테스트 실행 환경)까지 숨겨, 타이틀에서 F9(화면 돌리기)가 되지 않았습니다. 이제 됩니다.
  - 테스트 실행 환경의 창 크기 바꾸기를 장면 update 밖(다음 프레임 첫머리)에서 합니다. 영웅 선택 화면처럼 `super.update()` 뒤에 제 멤버를 도는 장면에서 `this.members is null` 이 나던 것을 막습니다. Windows 처럼 바로 다시 그리는 환경(`SYNC_RESIZE`)에서 재현됐습니다.
- **손상된 값**(형이 틀린 칸 · 없는 창 · 모르는 종류):
  - 게임은 쓸 수 있는 것만 씁니다. 새 칸은 안전한 읽기(`gi` · `gf`)를 쓰고, 공통 규칙은 틀린 값 대신 기본값을 씁니다.
  - 그래도 만들다 실패하면 원작 타이틀을 숨기지 않고 그대로 둡니다 (예전에는 숨긴 뒤 만들어, 실패하면 검은 화면이 될 수 있었음).
  - 편집기는 멈추지 않고, 검사(F7)가 오류로 알립니다. 예전 검사 줄이 `null` 버튼에서 멈추던 것도 고쳤습니다.

## 3. 미리보기와 런타임의 공통 렌더링 방식

그리는 엔진은 다릅니다 (편집기 = 캔버스, 게임 = noosa/OpenGL). 그래서 **데이터 · 배치 · 스타일 · 시간 계산을 한 규칙으로** 두고, 같은 그림 · 글꼴 파일을 씁니다.

| 공유 | 편집기 | 게임 | 같음을 확인하는 방법 |
|---|---|---|---|
| 규칙 (버튼 목록 · 배치 · 묶음 애니메이션 · 상태 모양 · 효과 · 요소 자리 · 정보 칸 · 창 배치) | `js/titlemodel.js` (`PDM.titleModel`) | `MakerTitleModel.java` (게임 라이브러리를 쓰지 않는 순수 자바) | `run.js` 가 자바를 실제로 컴파일 · 실행해 같은 입력 816개의 결과를 비교 |
| 그림 | 게임 저장소의 `chrome.png` 9조각 · `icons.png`(Icons.java 를 읽어 자리) · `banners.png`, 프로젝트가 바꾼 그림이 있으면 그것 | 같은 파일 | 캔버스 픽셀 검사 (창 가운데 = WINDOW 조각 색) |
| 글꼴 · 줄 | `pixel_font.ttf` · `droid_sans.ttf` 를 읽어 씀. 줄 높이 = round(크기 × 배율 × 0.75) ÷ 배율, 줄 간격 2, 낱말 사이 −0.667 (원작 RenderedTextBlock 과 같은 규칙) | 게임 글꼴 | 게임 높이와 0.000 차이, 폭은 ≤ 0.93 차이 |
| 화면 크기 · 배율 | 테스트 플레이 실행 환경(`PDM.testEnv`)과 같은 계산. 데스크톱 판은 밀도 1 → 1280×800 = ×3 → 427×267 (올림, 원작 PixelScene) | 실제 창 | 게임과 같은 427×267 · 390×180 · 154×334 |
| 시간 · 보간 | `fxValue` · `groupAnim` · `heldStep` | 같은 함수 (자바) | 816개 비교에 효과 176 · 동안 20 포함 |

- 미리보기 모드: 실제 화면(마우스를 올리면 오버) · 편집 윤곽(따로 그린 겹이라 게임 화면 그림에는 들어가지 않음) · 버튼 상태 고정(기본 · 오버 · 키보드 포커스 · 눌림 · 비활성) · 창 미리보기 · 재생 / 멈춤 / 처음부터 · 저장된 게임 있음/없음 · 보기 배율.
- 프레임 루프: 미리보기 하나에 requestAnimationFrame 하나만 씁니다.
  - 다른 탭을 보는 동안에는 그리지 않습니다.
  - 탭을 닫으면 다시 깨우는 것이 없어 멈춥니다 (남는 타이머 없음).
  - 다시 그릴 때마다 쉬었다가 이어집니다. `ui-title.js` 의 확인값: 열림 4~5회/초, 5번 다시 연 뒤 5회/초, 닫음 0회/초 (headless 브라우저의 프레임 속도).
- **차이가 남는 것** (같다고 보고하지 않음):
  - 글자 폭 — 캔버스와 FreeType 의 글리프 폭 차이로 한 줄당 ≤ 1px. 가운데 · 오른쪽 정렬 글의 자리가 그만큼 다를 수 있습니다.
  - 떠오르는 폐허 배경 · 입자 — 게임은 무작위, 미리보기는 시간으로 정해진 자리라 순간 모양이 다릅니다.
  - 횃불(Fireball 입자)은 비슷한 빛으로만 그립니다.
  - 창 그림자는 원작 ShadowBox 대신 반투명 사각형입니다.
  - 체크 상자 · 슬라이더는 원작 모양을 흉내 낸 그림입니다.
  - 버전 글 — 게임은 실행한 판의 버전, 편집기는 `build.gradle` 의 버전.
  - 버튼 글 — 게임은 플레이어의 게임 언어, 편집기는 게임 저장소의 한국어 글.

## 4. 배경 · 이미지 · 텍스트 편집

- 왼쪽 목록 → **배경 · 그림 레이어** (6차 기능 그대로: 게임 배경 · 원작 아치 · 떠오르는 폐허 직접 설정 · 색 · 그라데이션 · 아래쪽 어둡게 · 입자 · 그림 레이어). 미리보기에 입자도 그립니다 (시간으로 정해진 자리).
- **로고**: 게임 로고 · 내 그림 · 글자 · 없음, 배율 · 위치 · 움직임 · 빛 · 횃불. 캔버스에서 끌면 좌우 · 위아래 이동.
- **글 · 그림 요소** (새):
  - 목록 "+ 글" · "+ 그림". 보이기(👁) · 위/아래(그리는 순서) · 복제(새 id) · 삭제(되돌리기로 복구).
  - 겹: 로고 뒤 / 버튼 위. 보이는 때: 늘 / "화면을 누르세요" 동안 / 메뉴가 열린 뒤.
  - 글: 문구 · 글자 크기 · 색 · 정렬 · 줄바꿈 폭(넘으면 다음 줄) · 대체 문구.
  - 그림: 파일 · 배율 · 기울기.
  - 공통: 위치(0~1) · 기준점 · 이동 · 투명도 · 안전 영역 안 · 효과(나타날 때 · 늘).
  - 정렬 단추: 가로/세로 가운데 · 네 끝 (안전 영역 기준).
- 캔버스: 누르면 고름(위에 그린 것부터) · 끌어 옮김 · 고른 것의 오른쪽 아래 모서리를 끌어 크기(글 = 줄바꿈 폭, 그림 = 배율, 창 = 너비, 자유 배치 버튼 = 너비 · 높이) · 화살표 1px / Shift 10px.
  - 끄는 동안에는 복사본만 바꾸고, 놓을 때 한 번 저장합니다 (되돌리기 한 번).
  - 화면 밖으로 나간 것 · 겹친 것은 왼쪽 목록에서 고릅니다.
- **지원하지 않는 글 속성** (게임 글꼴이 하지 않아 목록에 두지 않음): 글꼴 고르기(게임 글꼴만) · 굵게 · 자간 · 줄 간격 · 외곽선/그림자 설정(게임 글꼴의 검은 테두리 고정) · 글 회전.

## 5. 버튼 및 상태별 스타일 편집

- 목록 → **버튼 묶음**:
  - 배치(게임 원래 · 격자 · 세로 한 줄 · 자유 배치) · 시작 높이 · 폭 · 높이 · 간격 · 좌우 이동.
  - 묶음 애니메이션 (6차 그대로).
  - **모든 버튼의 상태별 모양**.
- 목록 → **버튼 하나**:
  - 글자 · 보이기 · 누를 수 있음(끄면 비활성) · 아이콘 · 글자 크기 · 키보드 순서 · 동작(9장).
  - 자유 배치면 자리 · 크기.
  - **이 버튼의 상태별 모양** · 효과.
  - ID 는 바꿀 수 없음 (새 버튼은 겹치지 않는 id 를 만듦).
- 상태 5개와 **우선순위**: 비활성 > 눌림 > 키보드 포커스 > 포인터 오버 > 기본.
  - 비활성 버튼은 포인터가 올라가도 비활성 모양입니다.
  - 같은 상태 안에서는 버튼 칸 > 묶음 칸 > 게임 기본입니다.
  - 상태에 없는 칸은 아래 상태의 값을 씁니다 (예: 비활성 + 오버 → 투명도는 오버 값).
- 게임 기본 상태 모양 = 원작 StyledButton: 눌림 = 바탕 밝기 1.2, 비활성 = 글자 투명도 0.3.
  - 원작에 없는 키보드 포커스는 밝기 1.3 으로 보입니다.
  - 오버는 원작처럼 바뀌지 않습니다.
- 상태마다 바탕 그림: chrome.png 조각 또는 내 9조각 그림. 그림이 없거나 못 읽으면 그 위 단계 → 회색 단추로 대체합니다.
- 오버는 PC 의 실제 포인터 자리로 정합니다 (휴대폰에는 오버 없음). 창이 떠 있으면 뒤 버튼은 오버되지 않습니다.
- **지원하지 않음**: 상태별 아이콘 · 상태별 글자 크기 · 굵기 · 좌우 안쪽 여백 · 테두리 · 그림자 색 (원작 StyledButton 이 아이콘 · 글자를 가운데 배치하고 바탕은 9조각이라, 바탕 조각 · 그림으로 정함).

## 6. 버튼 애니메이션

- **묶음 애니메이션** (6차 그대로): 나타날 때(서서히 · 위아래 · 좌우 · 떨어지며 튕김 · 가로로 튀어나옴) + 나타난 뒤(둥실 · 살랑 · 깜빡). 시간 · 버튼 사이 간격 · 거리.
- **효과** (새, 버튼마다 · 요소마다):

  | 시작 조건 | 시간 |
  |---|---|
  | 나타날 때 (메뉴가 열릴 때, 버튼은 묶음 간격만큼 차례로) | 등장 시계 |
  | 늘 | 화면 시간 |

## 8. 동적 정보 표시

- 글 요소 · 창 글 · 창 제목에 `{이름}` 을 넣으면 게임이 실제로 아는 값으로 바뀝니다. 다른 글은 그대로입니다 (정적 글).

  | 이름 | 값 (게임) | 없을 때 |
  |---|---|---|
  | `{gameName}` · `{author}` | 프로젝트 설정의 게임 이름 · 만든 사람 | 빈 글 |
  | `{version}` · `{versionCode}` | `Game.version` · `Game.versionCode` | — |
  | `{saveCount}` | 저장된 게임 수 (`GamesInProgress`) | 0 |
  | `{lastHero}` · `{lastDepth}` · `{lastLevel}` | 마지막으로 한 저장 게임의 영웅 · 깊이 · 레벨 (예전 판은 슬롯 번호 순) | **값 없음 → 대체 문구** |
  | `{date}` | 오늘 (YYYY-MM-DD) | — |

- 값 하나라도 없으면 대체 문구(있으면)를 씁니다. 모르는 이름은 바꾸지 않고, 검사가 오류로 알립니다 (가짜 값을 넣지 않음).
- 편집기 미리보기 값: 게임 이름 · 만든 사람 = 프로젝트, 버전 = 게임 저장소 `build.gradle`, 저장 정보 = "저장된 게임 있음 (예시 값)"을 켜면 예시(전사 · 3층 · 5레벨), 끄면 없음(대체 문구).
- 긴 글은 줄바꿈 폭으로 줄을 나눕니다. 값은 화면을 만들 때 한 번 정해, 흔들리지 않습니다.
- 안전 영역 안에 두면(기본) 노치 · 내비게이션 바를 피합니다.

## 9. 버튼 동작 연결

| 동작 | 게임에서 |
|---|---|
| (게임 버튼의 원래 동작) | 들어가기 · 지원 · 랭킹 · 일지 · 소식 · 변경 · 설정 창 · 소개 (6차와 같음) |

- 지원하지 않는 동작(이벤트 · 명령 실행)은 목록에 없습니다. 타이틀에는 던전 · 영웅이 없어 이벤트를 실행할 수 없습니다.

## 12. 미검증 환경 및 알려진 제한 사항

| 수준 | 결과 |
|---|---|
| 화면 시뮬레이션 (PC 데스크톱 판 · xvfb) | 위 결과 |
| 에뮬레이터 · 실제 휴대폰 | **하지 않음** (안드로이드 SDK 없음) — 실제 터치 · 실제 노치(INSET_BLK) · 앱 전환 · 키보드 없는 기기에서 확인하지 못함 |
| Windows 실제 실행 | **하지 않음** (바로 다시 그리기는 `SYNC_RESIZE` 로 흉내만) |
| iOS · 웹 판 | **하지 않음** (게임 끄기 숨김은 코드로만) |

- 테스트 플레이의 휴대폰 흉내는 글자를 PC 창 배율(×3)로 만듭니다. 실제 휴대폰은 기기 배율(×6 등)이라 글자 높이가 ≤ 0.2 다를 수 있습니다. 편집기는 실제 기기 배율로 그리고, 자동 비교만 흉내 배율을 씁니다.
- 글자 폭은 캔버스와 게임의 글리프 폭이 달라 한 줄당 ≤ 1px 다를 수 있습니다 (3장).
- 6차까지의 칸(로고 · 그림 레이어 등)이 손상되면 새 칸처럼 하나씩 건너뛰지 않고, 원작 타이틀로 돌아갑니다 (검은 화면은 아님).
