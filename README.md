# 픽셀 던전 메이커 (가제) — PDMaker

Shattered Pixel Dungeon(SPD) 기반 게임을 **코드 없이** 만드는 도구입니다.
에디터(Electron)가 프로젝트 폴더에 JSON · PNG · 소리 파일을 저장하고, 게임 저장소(SPD 소스) 위에 설치한 **pdmaker 런타임**이 그 폴더를 읽어 그대로 실행합니다.
필요하면 영웅 · 아이템에 Java 코드를 직접 써서 게임과 함께 컴파일할 수도 있습니다.

## 1. 준비 · 실행

PDMaker 폴더 하나에 필요한 것이 모두 들어 있습니다. 기준 게임 저장소는 `game/shattered-pixel-dungeon-master` (SPD 4.0.0)입니다.
다른 게임 저장소도 쓸 수 있습니다: Shattered Pixel Dungeon 2.5 ~ 4.0 과 그 패키지(`com.shatteredpixel.shatteredpixeldungeon`)를 그대로 쓰는 모드 (확인: 2.5.4 · 3.0.2 · 3.3.8 · 4.0.0 · 4.0.2). 원작 Pixel Dungeon · 패키지를 바꾼 파생작(RKPD2 등) · 체력이 long 인 파생작(Experienced PD)은 지원하지 않으며, 프로젝트 설정 › 게임 런타임에 이유가 표시됩니다.

1. **Node.js LTS** 설치 (한 번만) — `make-release.bat` 로 만든 배포 zip 에는 Electron 이 들어 있어 필요 없습니다.
2. `start-editor.bat` 더블클릭 → 처음에는 `npm install` 로 Electron 을 받습니다 (1~2분).
3. 시작 화면에서 **새 프로젝트** 또는 **프로젝트 열기** (최근 프로젝트 목록에서 별명 · 경로 다시 지정 · 목록에서 빼기도 됨).
4. **▶ 테스트 플레이** (F5) — 게임 저장소에 런타임을 자동으로 설치 · 갱신하고 gradle 로 게임을 켭니다.

- Java(JDK 17+)가 없으면 처음 테스트 플레이 때 에디터가 Eclipse Temurin 21 을 내려받습니다 (약 190MB). 처음 빌드 때 Gradle · 라이브러리를 내려받으므로 인터넷이 필요합니다.
- 안드로이드 SDK 가 없는 PC 에서도 데스크톱 테스트 플레이는 됩니다 (android 모듈을 건너뜀).
- 에디터 아래 **출력** 창에 빌드 · 게임 로그가 나옵니다. `[PDMaker] PDMaker 프로젝트 불러옴 …` 줄이 없으면 런타임이 연결되지 않은 것입니다.
- 빌드가 실패했을 때 PDMaker 창이 뒤에 있으면 작업 표시줄 아이콘이 깜빡입니다.
- **웹 모드**: `editor/renderer/index.html` 을 웹 서버로 열면 Electron 없이 화면만 볼 수 있습니다 (저장은 브라우저 안, 테스트 플레이 불가 — 개발 · 확인용).
- **업데이트**: 도움말 › "PDMaker 업데이트 확인…" (시작할 때도 조용히 확인). git 폴더면 `pull`, 아니면 GitHub 의 main ZIP 을 받아 덮어씁니다 (`game/` 은 그대로).

## 2. 새 프로젝트

- **만들 위치**를 고르면 그 안에 **프로젝트 이름으로 폴더**를 만듭니다 (끌 수 있음 · 만들 경로를 미리 보여 줌).
- 프로젝트 이름과 함께 **게임 이름(appName) · 패키지 이름(appPackageName)** 을 정합니다 — 게임 창 제목과 세이브 폴더가 이것으로 정해져 원작과 섞이지 않습니다.
- 이어서 **게임 저장소**를 고릅니다. PDMaker 의 `game/` 안에 있는 저장소는 자동으로 찾고, 다른 SPD(모드) 소스 폴더를 고르면 원작 영웅 · 캐릭터 목록을 그 저장소에 맞춥니다.

새 프로젝트는 **원작 그대로** 시작합니다.

| 항목 | 내용 |
|---|---|
| 맵 | 하수도 · 감옥 · 동굴 · 드워프 도시 · 악마의 전당 5구역 × 5층 (자동 생성, 5 · 10 · 15 · 20 · 25층 보스) |
| 영웅 | 원작 6명 (전사 · 마법사 · 도적 · 사냥꾼 · 결투가 · 성직자) — 그림 · 특성 · 전직 · 직업 능력은 게임 원래 것 |
| 캐릭터 | 원작 72명 (몬스터 59 · 보스 5 · NPC 8) — "게임 동작 그대로"를 끄면 데이터로 고쳐 쓰는 캐릭터 |
| 아이템 · 방 | 게임 아이템 282개와 게임 기본 방 172개가 목록에 그대로 나옴 (복사해서 고치거나 상속해서 코드로 바꿈) |
| 화면 | 게임 원래 타이틀 · 영웅 선택 화면, 원작 가운데 대사창 |

## 3. 화면 구성

GameMaker 식 IDE 입니다: **메뉴 · 도구 모음 / 리소스 목록 · 탭 작업 공간 · 인스펙터 / 출력 · 검사**.

- **도구 모음**: 새로 · 열기 · 저장 · 다른 이름으로 저장 | 프로젝트 내보내기 · 가져오기 · 게임 파일 내보내기 | 실행 취소 · 다시 실행 | 검사 · 빌드 정리 | ▶ 테스트 플레이 · ■ 중지 | 확장 기능 · 테마 · 설정
- **테마**: 기본은 "시스템 따르기"(OS 의 밝은/어두운 모드 · 강조색). 보기 메뉴(또는 ◐)에서 고정하거나 강조색을 바꿉니다.
- **리소스 목록**: 이름 검색 · 세부 검색(분류 · 종류), 끌어 놓아 순서 · 분류 바꾸기, 오른쪽 클릭 메뉴.
- **창 · 복사**: Ctrl+W 로 떠 있는 창(없으면 지금 탭) 닫기, Ctrl+C / Ctrl+V 로 리소스 · 맵 노드 · 맵 오브젝트 · 이벤트 명령 · 이펙트 등 목록 항목 복사 · 붙여넣기 (다른 프로젝트에도 붙여 넣을 수 있음).
- **묶음 버튼 (▾)**: 내보내기 · 빌드 · 설정, 맵 편집기의 보기 켜고 끄기, 영웅의 코드 보기는 ▾ 메뉴에 모았습니다.
- **설명문**: 편집 화면의 설명은 기본으로 숨겨져 있고, 그 기능(입력칸 · 버튼 · 섹션 제목, ⓘ 표시)에 마우스를 올리면 상자로 나옵니다. 보기 › "설명문: …" 에서 항상 펼쳐 보기 · 숨기기로 바꿀 수 있습니다.
- **단축키**: 편집 › "단축키 설정…" 에서 저장 · 테스트 플레이 · 탭 이동 · 그리기 도구 등의 키를 바꿀 수 있습니다.
- **리소스 공용 메뉴**: 캐릭터 · 아이템 · 이벤트 · 맵 오브젝트 · 방 템플릿은 목록 오른쪽 클릭과 편집 화면 맨 위 줄에서 이름 바꾸기 · id 바꾸기(쓰는 곳도 함께) · 복제 · 쓰는 곳 · 삭제.
- **편집 도우미**: 모든 편집은 실행 취소(Ctrl+Z) 가능. 숫자 칸은 마우스를 올리고 휠(Shift = 10씩), 아이템 칸은 검색 · 그림이 있는 목록. 편집해도 화면 위치 · 접은 섹션이 그대로 유지됩니다.

## 4. 주요 기능

### 맵
- **맵 그래프**: 노드(맵 하나)를 놓고 연결(계단)로 잇고 그룹(구역)으로 묶습니다. 빈 곳 더블클릭 = 새 노드, 노드 네 면의 점을 끌어 연결 (그냥 = 통로 · Shift = 갈림길 출구(무게대로 무작위) · Alt = 샛길 계단(조건)).
- **그룹 제목 더블클릭** = 그룹 노드들의 설정을 한꺼번에 바꾸거나(테마 · 보스 · 스폰 · 배경음 …) 광원 · 방 · 몬스터를 한꺼번에 추가.
- **노드 = 맵**: 자동 생성 · 직접 그리기 · 혼합. 자동 생성은 **구성 블럭**(구조 · 분위기 · 방 수 · 넣을 방)으로 층 구성을 정합니다.
- **맵 편집기**: 펜 · 사각형 · 채우기 · 지우개 · 선택, 크기 손잡이, 입구 · 출구 배치와 연결, 스폰 구역, 오브젝트(캐릭터 · 아이템 · 이벤트 · 광원 · 이펙트 · 맵 오브젝트 · 투명 출입구 · 발판 · 플레이어 시작 위치). 오브젝트를 오른쪽 클릭으로 옮기거나 설정.
- **영역 편집 · 여러 오브젝트** (⇱ 선택): 빈 곳에서 끌어 영역을 고르고 Ctrl+C / Ctrl+X / Ctrl+V(미리보기를 보며 원하는 칸을 눌러 붙임 — 여러 번 가능) · Delete. 지형 · 모든 타일 레이어 · 스폰 구역 · 오브젝트가 함께 옮겨지고 빈 칸은 투명. Shift/Ctrl+클릭으로 오브젝트 여러 개를 골라 함께 끌기 · 방향키 이동 · 공통 속성 한꺼번에 바꾸기 · 복제 · 삭제. 모두 실행 취소 가능.
- **조합 타일** (확장 기능 — 끄면 게임에서도 꺼짐): 여러 스프라이트(레이어 · 위치 · 순서 · 불투명도 · 발광) + 실제 광원 · 이펙트 · 함정을 묶은 프리셋. 맵에 오브젝트로 놓거나 자동 생성(벽 앞면 · 바닥 · 풀 · 물 … · 확률 · 간격 · 최대 · 테마)에 등록 — 예: "벽면 광원 장식". 배경을 투명하게 분리한 타일셋은 밑그림 규칙으로 예전 일체형 모습 그대로 그립니다.
- **편집 대상 레이어** (5차): 팔레트의 레이어 목록(위 → 아래)에서 한 줄을 누르면 그리기 · 지우개 · 영역 복사/붙여넣기가 **그 레이어에만** 작용합니다 (아래 레이어 · 지형은 그대로, 칸의 지형은 남은 가장 위 타일로 다시 정해짐). 👁 보이기 · 🔓 잠금 · 다른 레이어 흐리게. 「⛰ 지형 · 전체」 = 예전처럼 지형 + 모든 레이어. 팔레트 묶음(그릴 것 · 타일 레이어 · 오브젝트 · 구역 · 고급)은 접을 수 있고 상태를 기억합니다.
- **타일 레이어 · 함정**: 지형(게임 판정) 위에 사용자 타일을 여러 레이어(기본 · 풀 · 벽 · 벽 장식 · 광원 · 효과 · 전경 — 추가 · 순서 · 캐릭터 위/아래 · 게임 표시 · 막힘 설정)로 겹쳐 칠합니다. 함정은 지형이 아니라 오브젝트 — 게임 함정 31종을 바닥 위에 놓고, 숨김 · 작동함을 정합니다 (게임 규칙 그대로 작동). 예전 맵은 열 때 자동으로 바뀝니다.
- **방 템플릿**: 자동 생성 맵에 끼워 넣는 방. 뒤집기 · 돌리기 · 무작위 칸으로 들어갈 때마다 변형.
- **맵 세부 그리기**: 맵 전체를 한 장의 그림으로 덧그려 타일 대신 보여 줌.

### 빛 · 연출
- **광원**: GameMaker 식 점광원(벽 · 물건 · 캐릭터 그림자) — 광원 오브젝트, 맵 오브젝트 · 아이템 · 이펙트의 빛, **지형 광원**(물 → 발광 호수), **자동 광원**(특정 지형마다 자동 배치). 영웅이 못 보는 칸에서는 꺼집니다.
- **빛 레이어 · 번짐**: 스프라이트 · 타일셋 옆의 `_light.png` 를 발광으로 덧그림.
- **배율 적용 (해상도)**: 타일셋처럼 캐릭터 · 영웅 · 맵 오브젝트 · 아이템 · 사용자 타일 · 이펙트 알갱이 그림도 ×0.25~×4 로 다시 만들어 세밀하게 — 게임 화면에서의 크기는 그대로.
- **이펙트 · 파티클** (Defold 식 이미터) · **화면 필터** (비 · 눈 · 안개 · 글리치 · 레터박스 …) · **글자 연출 (APNG)** · **예고편 컷신** · **노드 합성기** (노드로 타일 · 스프라이트 그림 만들기) · **모션 랩** (CSS · JS 로 움직이는 그림 → 픽셀 아트로 구워 화면 필터 · 이펙트 · 맵 오브젝트 · 아이템 · 노드 합성기에 보냄 — 화면 필터의 코드 층 · 글자 연출과 같은 굽는 부품).

### 영웅 · 캐릭터 · 아이템
- **영웅**: 원작 구조 그대로 — 주문서와 주문, 전직(텐구의 가면), 직업 능력(왕의 왕관), 특성 트리(포인트 최대 4, 옵션으로 10). 바탕 직업을 비우면 **완전히 새 영웅**. 영웅 선택 화면 · 해금 조건 · 저장 슬롯 초상화까지 프로젝트 영웅으로.
- **Java 코드**: 영웅 · 아이템 · 전직 · 능력 · 특성의 "코드" 칸 → `pdmaker/gen/*.java` 로 만들어져 게임과 함께 컴파일. 컴파일 오류는 에디터의 어느 칸 몇째 줄인지 알려 줍니다.
- **캐릭터**: 원작 캐릭터를 그대로 쓰거나 데이터 캐릭터로 고침. 동료 · 상인 · 퀘스트 · NPC 이주.
- **아이템**: 게임 `items` 폴더 구조의 분류. 그림(게임 시트 · 복사해서 고치기 · 그리기 · PNG), 게임 아이템 그림 바꾸기 · 상속, 소리(쓸 때 · 던지는 순간 · 맞힐 때 · 주울 때 · 장착 — 기본값은 게임 코드에서 읽어 표시), 드랍 테이블.

### 소리 · 화면 · 이야기
- **사운드**: ogg · mp3 · wav 가져오기(게임이 못 읽는 24비트 · float WAV 는 자동으로 16비트로), 게임 소리 복사, 파형 편집, 효과음 합성기. 소리는 각 세부 설정(아이템 · 캐릭터 · 주문 · 대사창 …)에서 고릅니다. 배경음은 노드 → 그룹 → 테마 순.
- **타이틀 화면** · **대사창** · **게임 텍스트** · **업적** — 게임 원래 화면을 그대로 두거나 바꿉니다.
- **게임 UI 테마** (6차 — 리소스 「🎨 게임 UI 테마」, `theme.json`): 게임 UI 의 모습 = 프로젝트의 인게임 UI 스프라이트(`chrome.png` · `status_pane.png` … — 「UI 그림」에서 바꿈). PDMaker 가 더하는 대사창 · 이름표 · 선택지 · 연출 배속 표시줄도 같은 `chrome.png` 의 9조각으로 그려지고, UI 마다 쓸 조각을 고릅니다 (실제 그림으로 미리보기). 글자 색 7개 · 대비 검사(글자 ↔ 그 조각의 색). 대사창 모양 · 글자 색 빈 칸 = 테마를 따름. 예전 프로젝트는 theme.json 이 없으면 원작 모습 그대로.
- **스크린 · 카메라 연출** (6차 — 이벤트 명령 묶음 "카메라 / 스크린"): 스크린 이동(타일 · 월드 좌표 · 캐릭터 · 이벤트, 시간 · 보간 · 기다림) · 팔로우(대상 · 부드럽게 · 세기 · 화면 자리) · 쉐이크(강도 · 시간 · 속도 · 감쇠 · 방향) · 리셋(부드럽게/바로 · 영웅 따라가기). 맵 밖을 보지 않고, 이벤트가 끝나면 영웅에게 돌아감.
- **대사 글꼴 · 연출** (5차): 글자 크기 · 굵게 · 정렬 · 글자/줄 간격 · 여백 · 강조(`**…**`) 색 · 글자 속도 · 글자가 나타날 때 연출(흐리게 · 올라옴 · 내려옴 · 튀어나옴 · 떨림 · 물결, 강조 글자만도). 우선순위: 기본값 → 대사창 설정(프로젝트) → 이벤트의 **대사 스타일** 명령 → 대사 명령의 글꼴 · 출력 · 연출 탭. 미리보기 탭은 게임과 같은 계산으로, 프로젝트 실행 환경의 화면 비율로 재생합니다.
- **스토리 · 이벤트** (확장 기능): 스위치 · 변수 · 루트 · 엔딩, 입장 문구 · 잠긴 맵 · 구역 소개 화면, RPG Maker 식 이벤트 페이지(출현 조건 · 이미지 · 자율 이동 · 발동)와 명령 목록.
- **마음 시스템** (확장 기능): era 식 관계 · 감정 시스템 (호감 · 신뢰 · 감정 게이지 · 결정 · 관계 능력 · 흔적 · 이정표). 화면에 보이는 이름은 모두 **용어 관리**(`terms.json`)에서 바꿀 수 있습니다.

## 5. 테스트 플레이 · 내보내기

- **테스트 플레이 방식** (프로젝트 설정): gradle `desktop:debug`(기본 — 게임 원래 실행 작업, 버전 -INDEV) 또는 PDMaker 테스트 실행(-PLAYTEST, 세이브 폴더 분리).
- **실행 환경** (5차 — 도구 모음 실행 환경 단추 · 실행 › 실행 환경 설정…, 프로젝트마다 `project.json` 의 `testplay`): PC · 작은 PC 창 · 모바일 가로/세로 · 사용자 지정(기기 px · dpi), UI 배율, 회전 허용(게임에서 F9), 안전 영역 미리보기(노치 · 직접), 터치 표시, 디버그 정보, 시작 배속. 편집기가 기기 픽셀 → 게임 배율 → 논리 화면 → PC 창을 계산해 보여 주고, 게임은 그 창 · 배율 · 안전 영역으로 켜집니다. **PC 에서 흉내 내는 화면 시뮬레이션** — 에뮬레이터 · 실제 기기 확인을 대신하지 않습니다.
- **연출 배속** (6차): 대사 · 이벤트 · 카메라 연출 중에만 화면 아래 배속 표시줄 (▶ 1x · 1x 2x 4x 16x · 스킵, F6 · F10). 연출이 끝나면 늘 1×. 테스트 플레이에서는 늘, 내보낸 게임에서는 「게임 UI 테마 › 연출 배속 표시줄」을 켰을 때. 테스트용 키: 대사 완성 F7 · 다음 대사 F8 · 화면 돌리기 F9 · 디버그 정보 F12.
- **빌드 정리**: `gradlew clean` — 이상한 컴파일 오류가 계속될 때.
- **다른 이름으로 저장** (Ctrl+Shift+S): 프로젝트 폴더 전체를 복사하고 그쪽에서 계속 (상대 경로는 자동으로 고침).
- **프로젝트 내보내기 · 가져오기** (Ctrl+E): 프로젝트를 `.pdmproj`(ZIP) 하나로 묶음 — 백업 · 공유용.
- **게임 파일 내보내기** (Ctrl+Shift+E): 저장 → 검사 → 런타임 설치 · 코드 생성 → gradle 빌드 → `<게임 이름>/` 폴더.

| 종류 | 결과 | 필요한 것 |
|---|---|---|
| JAR | `<이름>.jar` + `.bat` + `project/` | 받는 PC 에 Java 17+ |
| Windows 실행 파일 폴더 | Java 가 들어 있는 `.exe` 폴더 + `project/` | 처음엔 JDK 를 내려받아 몇 분 걸림 |
| Windows 설치 파일 | `<이름> 설치.exe` 하나 (프로젝트는 안에 zip 으로) | Windows 에서만 · WiX 3 (없으면 처음 한 번 내려받음) |
| 안드로이드 앱 | 서명된 `.apk` | Android SDK(Android Studio) · 서명 키(프로젝트 `signing/` 에 자동으로 만들거나 내 키스토어 — 잃어버리면 업데이트 불가) |

- PDMaker 자체 exe: `build-exe.bat` → `editor/dist/PDMaker x.y.z.exe` (포터블, 런타임 소스 포함).
- 다른 PC 에 줄 zip: `make-release.bat` → `pd-maker-release.zip` (game/ · Electron 포함, .git · build 제외).
