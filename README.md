# 픽셀 던전 메이커 (가제) — PDMaker

Shattered Pixel Dungeon 기반 게임을 **코드 없이** 만드는 도구입니다.
에디터(exe)가 프로젝트 폴더에 JSON·PNG 를 저장하고, 게임(game/shattered-pixel-dungeon-master + pdmaker 런타임)이 그 폴더를 읽어 바로 실행합니다.

자세한 설계: [DESIGN.md](DESIGN.md) · 게임 연결: [runtime/INTEGRATION.md](runtime/INTEGRATION.md)

## 폴더

```
pd-maker/
├─ README.md · DESIGN.md  안내 · 설계서 (아키텍처 · 데이터 형식 · 마음 시스템 · 이벤트 · 플러그인 · 단계)
├─ start-editor.bat       에디터 실행 (함께 든 Electron 이 있으면 바로, 없으면 Node.js 로 내려받아 실행)
├─ build-exe.bat          PDMaker.exe 만들기
├─ make-release.bat       다른 PC 에 줄 zip 만들기 (game/ · Electron 포함 → 받는 사람은 Node.js 없이 실행 · .git·build 제외)
├─ game/shattered-pixel-dungeon-master/       기준 게임 저장소 — 새 프로젝트·테스트 플레이·게임 내보내기에 씀
├─ docs/FOLDERS.md        폴더 구조 안내 (프로젝트 assets 표준 폴더 포함)
├─ editor/                에디터 (Electron)
│  ├─ main.js · preload.js 파일·테스트 플레이·런타임 설치 (메인 프로세스)
│  ├─ runtime-installer.js 게임 저장소에 런타임 넣기/빼기
│  ├─ renderer/           화면 (빌드 도구 없는 순수 JS — 바로 고쳐서 쓰면 됨)
│  │  ├─ js/editors/      편집기 한 개 = 파일 한 개 (world · map · hero · character · item · event · story · heart · sound · title · sprites · terms · plugins · legacy · project)
│  │  └─ js/…             store(저장·실행취소) · assets(그림 불러오기) · schema · cond(조건식) · heart-core · codegen …
│  └─ builtin-plugins/    내장 예제 플러그인 (screen-fx)
├─ runtime/               게임 런타임 Java 패키지 (…/pdmaker/*.java) + INTEGRATION.md
├─ sample-project/        (예전 mod-2 기준 샘플 — 시작 화면에는 더 나오지 않음)
├─ tools/
│  ├─ sample/             샘플 프로젝트 만들기 (make_sample.py · make_heart.js · make_sounds.js)
│  ├─ data/               게임 소스에서 에디터 데이터 뽑기 (extract_spd_items.py · itemsheet.py · gen_terms_java.js)
│  └─ playtest/           자동 플레이 테스트 (Linux 개발용, README 참고)
└─ references/            참고용 원본 (mod2-buffs: 아리아 버프 Brand · InkMark · Overheat)
```

## 실행

새 프로젝트는 원작 그대로 시작합니다: 하수도~악마의 전당 5구역 × 5층(보스 층 포함), 원작 영웅 6명(저장소에 추가된 아리아는 넣지 않음), 원작 몬스터·보스·NPC 73명(게임 원래 동작 그대로 — 끄면 직접 고쳐 쓰는 캐릭터), 원작 가운데 대사창, 게임 원래 타이틀 화면, 직업별 원작 시작 아이템·감정된 아이템(영웅 편집기 "목록대로 직접 주기"로 바꿔 쓸 수 있음).

PDMaker 폴더 하나에 필요한 것이 모두 들어 있습니다 (게임 저장소는 `game/` 안). 다른 PC 로는 `make-release.bat` 로 만든 zip 을 풀어서 씁니다.
Java(JDK 17+)가 없으면 처음 테스트 플레이 때 에디터가 내려받고(약 190MB), 처음 빌드 때 Gradle·라이브러리를 내려받으므로 인터넷이 필요합니다.

1. (release zip 이 아니면) [Node.js LTS](https://nodejs.org) 설치 (한 번만) — `make-release.bat` 로 만든 zip 에는 Electron 이 들어 있어 필요 없음
2. `start-editor.bat` 더블클릭 → 처음에는 `npm install` 로 Electron 을 받습니다 (1~2분)
3. 시작 화면에서 **새 프로젝트** (또는 **프로젝트 열기**)
4. **▶ 테스트 플레이** (F5) — 게임 저장소에 pdmaker 런타임을 자동으로 설치·갱신한 뒤 gradle 로 게임을 켭니다.
   새 게임을 시작하면 (어느 직업을 골라도) 영웅 아리아로 샘플 1층(시험장 입구)에서 시작합니다.
   - 1층 입구 계단 → 마녀의 마을(던전 밖 맵), 마을 광장의 봉인석을 밟으면 1구역 3층에 "잿불 갈림길" 계단이 생겨 4-2층 → 2-2구역으로 갈라짐
   - 2-1구역 3층의 출구는 70% 본래 길, 30% "물에 잠긴 층" (아이작식 무작위 갈림길)
   - 맵 화면은 노드 그래프: Space+끌기로 이동, 빈 곳 더블클릭으로 노드, 노드 오른쪽 점을 끌어서 연결 (그냥 = 통로 · Shift = 갈림길 출구 · Alt = 샛길)
   - 같은 두 노드 사이에 통로를 여러 개 만들 수 있고, 통로마다 다른 출구·입구를 씁니다 (연결을 눌러 출구·입구 번호 선택, 맵 편집기에 "출1"·"입2" 로 표시)
   - 직접 그린 맵은 "☗ 스폰 구역" 도구로 몬스터가 생기는 구역(초록)과 안 생기는 구역(빨강)을 칠하고, 속성의 "몬스터 스폰"에서 몬스터 목록·수·간격을 정합니다
   - 퀵슬롯의 「원소의 서」 → 주문, 코덱스(마법 베기·마법 화살), 화면 오른쪽 행동 버튼 → 원소 바꾸기(과열), 화면 오른쪽 위 하트 → 마음 창
   - 코드 예제: 아리아(공격 20% 화상 · 3마리 처치마다 회복 · 코드 주문 「비전 불꽃」), 잿불 지팡이(근접 무기 · 적중 시 화상),
     이끼 망토(갑옷 · 피격 시 속박), 씨앗 투척칼(투척 무기), 바람 방울(코드 행동 버튼 「흔들기」)
   - 에디터 아래 "출력" 창에 게임 로그가 나옵니다. `[PDMaker] PDMaker 프로젝트 불러옴 …` 줄이 없으면 런타임이 연결되지 않은 것

Node 없이 화면만 보고 싶으면: `editor/renderer/index.html` 을 웹 서버로 열면 "웹 모드"(저장은 브라우저 안, 테스트 플레이 불가)로 동작합니다.

## 화면 테마 · 도구 모음 · 내보내기

- **테마**: 기본은 "시스템 따르기" — Windows/macOS 가 밝은 모드면 밝게, 어두운 모드면 어둡게 바로 바뀝니다. 강조색도 OS 강조색을 따릅니다.
  **보기** 메뉴(또는 도구 모음 오른쪽 ◐)에서 테마를 밝게/어둡게로 고정하거나 강조색을 PDMaker 보라·직접 고른 색으로 바꿀 수 있습니다. 창 제목 표시줄·파일 대화상자도 같은 테마가 됩니다.
- **전직 · 직업 능력 · 특성 · 패시브의 코드**: 각 항목의 "코드 (세부 동작)" 에서 얻을 때(전직·선택·포인트·열림) · 쓸 때(직업 능력) · 매 턴 · 처치 · 명중/회피/피해/방어/속도 · 공격 적중/받음을 Java 로 직접 — 그 항목이 켜져 있을 때만 동작합니다.
- **주문서 그림**: 게임 아이템 그림에서 고르거나, PNG 파일 지정, 직접 그리기.
- **확장 기능** (도구 모음): 이벤트·시스템을 리소스 목록에 보일지 켜고 끕니다 (새 프로젝트는 꺼짐).
- **테스트 플레이 빌드**: 프로젝트 설정에서 PDMaker 테스트 실행(기본) 또는 gradle `desktop:debug`(INDEV 버전)를 고릅니다.
- **아이템 도감**: 프로젝트 아이템도 게임의 아이템 도감에 오릅니다.
- **영웅 선택 화면**: 게임의 직업 버튼 대신 프로젝트의 영웅(영웅 편집기에서 만든 영웅 포함)이 나옵니다. 순서는 리소스 목록 영웅 줄의 ▲▼, 글자는 영웅 편집기 "캐릭터 선택 화면"에서 정합니다. 시작 영웅을 정하면 그 영웅 하나만 나옵니다. 바탕 직업은 선택 사항입니다 — 비워 두면 **완전히 새 영웅**(게임 직업에서 시작 아이템·감정·특성·전직·직업 능력을 하나도 물려받지 않음, 영웅 편집기에서 정한 것만). 영웅 편집기의 **캐릭터 선택 화면** 에서 선택 화면 일러스트(그림 한 장 또는 시트 애니메이션, 오른쪽 맞춤 / 화면 높이 가득)와 선택 버튼 아이콘을 정합니다.
- **시작 화면의 최근 프로젝트**: 줄에 마우스를 올리면 ▲(위로) · 이름(목록에만 보이는 별명) · 경로(옮긴 폴더 다시 지정) · 삭제(목록에서만 빼기, 폴더는 그대로), 위쪽 "목록 비우기". 폴더가 없어진 항목은 빨간 줄로 표시.
- **도구 모음** (GameMaker 처럼 메뉴 아래 아이콘 줄): 새 프로젝트 · 열기 · 저장 · 다른 이름으로 저장 | 프로젝트 내보내기 · 가져오기 · 게임 파일 내보내기 | 실행 취소 · 다시 실행 | 검사 · 빌드 정리 | ▶ 테스트 플레이 · ■ 중지 | 테마 · 설정.
- **다른 이름으로 저장** (Ctrl+Shift+S): 프로젝트 폴더 전체를 빈 폴더에 복사하고 그쪽에서 계속 작업합니다. 게임 저장소 같은 상대 경로는 새 위치 기준으로 자동으로 고칩니다.
- **프로젝트 내보내기** (Ctrl+E): 프로젝트 폴더를 `.pdmproj` 파일 하나로 묶습니다 (ZIP 형식 — 백업·다른 PC·공유). **가져오기**는 빈 폴더에 풀어서 엽니다.
- **게임 파일 내보내기** (Ctrl+Shift+E): 저장 → 검사 → 런타임 설치·코드 생성 → gradle 빌드 → `<게임 이름>/` 폴더에 결과 + `project/`(게임 데이터)를 모읍니다.
  - JAR: `<이름>.jar` + `<이름>.bat`(더블클릭 실행). 받는 PC 에 Java 17 이상 필요.
  - 실행 파일 폴더: Java 가 들어 있는 `.exe` 폴더 (`gradlew desktop:jpackageImage` — 처음엔 JDK 를 내려받아 몇 분 걸림).
  - 게임은 jar/실행 파일 옆의 `project/` 폴더를 자동으로 찾습니다.
- **빌드 정리**: `gradlew clean` — 이상한 컴파일 오류가 계속될 때.

## exe 만들기

`build-exe.bat` → `editor/dist/PDMaker x.y.z.exe` (포터블). 런타임 소스가 함께 들어갑니다.
게임 exe 는 게임 저장소에서 `gradlew desktop:jpackageImage` (JRE 포함) 로 만들고, 실행 파일 옆에 프로젝트 폴더를 `project` 로 복사하면 됩니다.

## 사운드

리소스의 **🎵 사운드** 에서 소리 파일을 가져오거나(ogg·mp3·wav), 게임 소리를 복사하거나, 효과음 합성기(레이어·필터·리버브, 시작값 16개)로 직접 만들 수 있습니다.
파형 편집으로 자르기·페이드·음량·속도 조절 후 WAV 로 저장합니다. 등록한 소리는 `sound:<id>` 로 불리며,
이벤트 명령 "효과음/음악", 주문·직업 능력의 소리 칸, 맵 그래프에서 고릅니다.
맵 그래프에서 **그룹**을 고르면 인스펙터의 "음악"에서 테마 기본 음악 대신 탐험 곡(여러 곡 무작위)·긴장 곡(조건)·보스 곡을 그룹마다 정할 수 있고, 노드마다 따로 정한 배경음이 가장 우선입니다.

## 주문 · 전직 · 직업 능력 · 특성 · 과열 · 코덱스 (원작 구조)

예전 "스킬" 대신 원작(`actors/hero`)과 mod-2 의 구조를 그대로 데이터로 만듭니다. 예전 프로젝트의 스킬은 열 때 자동으로 주문으로 바뀝니다.

- **주문**: 원작 성직자처럼 영웅이 처음부터 **주문서**(충전·재충전)를 가지고, 1~4단계 주문을 겁니다. 레벨·특성·전직·직업 능력 조건을 채운 주문만 주문 창에 나오고, 길게 누르면 퀵슬롯 빠른 시전.
- **전직**: 텐구의 가면을 쓰면 영웅 편집기의 전직 중 하나를 고릅니다 (게임 전직 효과도 함께 켤 수 있음). 전직하면 특성 3단계가 열립니다.
- **직업 능력**: 왕의 왕관을 쓰면 직업 능력 중 하나를 골라 갑옷이 직업 갑옷이 되고, 갑옷 충전으로 발동합니다. 고르면 특성 4단계가 열립니다.
- **특성**: 원작처럼 레벨 2/7/13/21 에 열리는 단계별 트리. 능력치·주문/능력/코덱스 수치를 바꾸거나 주문을 배우게 하고, 3·4단계는 전직·능력 전용 특성을 둘 수 있습니다.
- **특수 기능 (코드)**: 게이지·스택·충전·자세 같은 영웅만의 시스템은 영웅 편집기 "코드" 칸의 **특수 기능 만들기** 에서 Special 도구(값 저장 · 버프 칸 표시 · 행동 버튼 → onAction)로 만듭니다. 예시 버튼: 과열식 게이지 · 연속 공격 스택 · 충전 행동 버튼.
- **코덱스**: 아이템 종류 "코덱스" — 겹쳐 쌓이는 사용형 마법 무기(근접·원거리·시전), 쓸 때마다 내구가 닳음. "그리모어" 가방에 담김.
- 이벤트 명령 "전직 · 직업 능력 고르기"로 가면·왕관 없이도 고를 수 있습니다.

게임에서는 **영웅 정보 창(왼쪽 위 초상화) → 특성 탭** 위쪽에 전직·직업 능력·주문, 아래에 특성이 나옵니다.
(샘플: 아리아 — 주문 9개(전직 전용 3), 전직 3(조화·과열·잉크 그리모어), 직업 능력 3, 과열 4원소, 코덱스 3종 + 그리모어, 특성 13개)

## 타이틀 화면

리소스의 **🏰 타이틀 화면** 에서 게임을 켰을 때의 화면을 꾸밉니다: 음악, 배경(게임 배경 그대로 — mod-2 는 숲·탑 10겹 가로 시차 배경, 반대 방향 가능 / 원작 아치를 위·아래·왼쪽·오른쪽으로 흘리기·아치 그림 바꾸기, 색·그라데이션, 그림 레이어 — 스프라이트 시트 애니메이션, 가로·세로 흐름, 흔들림·깜빡임·회전), 입자 효과(mod-2 마나 반딧불 포함),
로고(게임 로고·내 그림·글자 + 움직임), "화면을 누르세요"(mod-2 방식), 버튼(글자·아이콘·숨기기·동작 바꾸기·새 버튼·배치 + 나타나는/계속 움직이는 애니메이션), 버전 글자. 움직이는 미리보기가 있습니다.
**타이틀 스프라이트** 에서 타이틀이 쓰는 게임 그림(mod-2 배경 title0~9, 아치, 로고 banners, 버튼 테두리·아이콘)을 바로 고치거나 바꿉니다.
**메뉴 화면** 설정을 켜 두면 랭킹·모험 일지·변경·소개 등 메뉴 화면도 타이틀과 같은 배경·음악을 씁니다 (게임은 원래 이 화면들에서 theme 곡으로 바꿈).

## 대사창 · 스탠딩 일러스트

이벤트의 **대사 표시**는 게임에서 RPG Maker 처럼 화면 아래 넓은 대사창으로 나옵니다. 말하는 캐릭터의 일러스트가 대사창 옆에 크게 서고, 이름표와 ▼ 표시가 붙고, 글자는 한 글자씩 나옵니다.
- **캐릭터 편집기 → 초상화 · 표정 · 대사창 일러스트**: 기본 일러스트와 표정별 그림(투명 PNG), 크기 배율·위치·서는 쪽·뒤집기. 작은 미리보기가 있습니다.
- **리소스 → 💬 대사창**: 상자 모양(둥근 상자·게임 창·내 그림)·색·높이, 이름표, 일러스트 위치·높이, 글자 속도·소리, 선택지 위치. 빠른 시작 4종(밝은 둥근 상자·어두운 반투명·게임 창 느낌·원작 가운데 창).
- 주인공이 말할 때(화자 "주인공")는 영웅 편집기에서 연결한 캐릭터의 일러스트를 씁니다.
- 대사 바로 뒤에 선택지를 두면 대사창을 띄운 채로 선택지가 나옵니다. "표정 바꾸기"·"일러스트 표시/숨김" 명령도 게임에서 동작합니다.
- 글자 모양(색·크기·_강조_ 색·정렬)과 UI 그림(대사 상자·이름표·선택지·고른 선택지·▼)을 9조각 PNG 로 바꿀 수 있습니다. 선택지는 기본으로 화면 가운데에 나오고, 캐릭터에게 말을 걸 때 나오는 메뉴도 같은 대사창 방식입니다.
- 대사창·선택지가 떠 있는 동안에는 상태창·도구 막대·기록 같은 다른 UI 를 숨깁니다 (대사창 편집기 → 대사 상자 → "다른 UI 숨기기", 기본 켬).
- **레이아웃 직접 편집**: 대사창 미리보기에서 "레이아웃 직접 편집"을 켜면 대사 상자·글 영역·이름표·일러스트·선택지·▼ 영역을 끌어서 옮기고, 모서리로 크기를 바꾸고, 도구로 새로 그릴 수 있습니다. 타이틀 화면의 로고·버튼 영역도 같은 방식으로 편집합니다.
- **소리는 각 세부 설정에서**: 프로젝트 아이템(쓸 때·던질 때·주울 때·장착할 때, 코덱스는 맞을 때·빗나갈 때·다 닳을 때), 게임 아이템(아이템 트리의 ▫ 페이지 → 소리), 캐릭터(공격·다침·쓰러짐·말 걸기·목소리), 주문·능력, 대사창, 마음 시스템, 게이지. 비워 두면 기본 소리, "(소리 없음)"은 조용히. 소리 칸의 🎚 는 그 소리를 사운드 편집기에서 열고, 게임 소리면 프로젝트로 복사해서 파형을 편집합니다.
- **코덱스 연출**: 마법 그림(날아가는 화살·마법 칼날), 베기 동작, 연타, 퀵슬롯 자동 조준 (mod-2 코덱스와 같은 방식).
- 샘플: 아리아·미레유에 자리표시용 일러스트(`tools/sample/make_portraits.py`)가 들어 있습니다.

## 그림 관리

리소스의 **🖼 그림 관리** 에서 프로젝트의 모든 그림을 폴더별로 봅니다 (영웅 · NPC · 동료 · 몬스터 · 보스 · 아이템 · 효과 · 초상화(캐릭터별) · 일러스트 · 타일셋 · 타이틀 · UI).
그림마다 크기·쓰는 곳이 나오고, 편집(픽셀 편집기) · 바꾸기 · 이동/이름 바꾸기(쓰는 곳의 경로도 자동 수정) · 삭제(안 쓰는 그림만)를 할 수 있습니다.
**🧹 자동 정리** 는 쓰는 곳을 보고 그림을 표준 폴더로 옮깁니다. **게임 그림 바꾸기** 는 게임의 sprites/interfaces/effects/environment/splashes 그림을
프로젝트 `assets/game/<같은 경로>` 로 복사해 고치며, 테스트 플레이 때 게임이 원본 대신 그 그림을 씁니다 ("원래대로" = 복사본 삭제). 폴더 규칙은 [docs/FOLDERS.md](docs/FOLDERS.md).

## 편집 도우미

- 숫자 칸(개수·강화 등)은 마우스를 올리고 휠로 올리고 내립니다 (Shift = 10씩).
- 아이템을 고르는 칸은 눌러서 목록을 열고 글자로 걸러 고릅니다 (프로젝트 아이템 + 게임 아이템, 그림·스크롤바).
- 픽셀 편집기(스프라이트·아이콘·아이템 그림)에서 작업 영역 크기를 바꿀 수 있습니다 (그림 위치 9방향, +1 프레임, +1 줄).
- 영웅의 전직에 "전직 액티브"를 켜면: 적 처치 등 조건을 채울 때 게임 오른쪽 행동 버튼이 켜지고, 누르면 버프·피해·코드 효과가 나갑니다.
- 전직·직업 능력·주문의 아이콘은 게임 아이콘 외에 직접 파일(한 장 또는 시트의 칸)을 지정하거나 그릴 수 있습니다.

## 아이템 분류

- **아이템 그림**: 게임 시트에서 고르기 · 게임 그림을 복사해서 고치기 · 직접 그리기 · PNG 파일 고르기. PNG 그림도 게임 안(가방·바닥·퀵슬롯)에 그대로 나옵니다.
- **게임 아이템 바꾸기**: 아이템 트리의 게임 아이템(▫) 페이지에서 그림을 바꾸거나(게임 전체에 적용), "이 아이템을 바탕으로 코드 작성"으로 게임 클래스를 상속한 아이템을 만들어 Java 코드로 동작을 고칩니다.

아이템 분류는 게임의 `items` 폴더 구조를 따릅니다: 무기(근접·투척·다트·활), 코덱스(mod-2), 방어구, 아티팩트, 반지, 마법봉, 물약(특이·양조·엘릭서), 주문서(특이), 룬석, 마법, 폭탄, 음식,
가방(그리모어), 열쇠, 퀘스트, 장신구, 문서, 유품 + 재료·선물·기타. 분류에 따라 사용 버튼(마시기·읽기·먹기)과 소모 여부가 정해지고, 음식은 포만감만큼 배고픔을 채웁니다.
리소스 트리는 분류 › 세부 종류(예: 무기 › 근거리 무기 / 원거리 무기 / 투척 무기 / 다트)로 나뉘고, 프로젝트 아이템과 함께 **게임의 모든 아이템**(▫)이 나옵니다. 게임 아이템은 눌러서 보고, "복사해서 고치기"로 프로젝트 아이템을 만들 수 있습니다.

## 영웅·아이템에 Java 코드 쓰기

영웅/아이템 편집기의 **코드 (Java)** 칸에 쓴 코드는 ▶ 테스트 플레이 때 게임 저장소의 `…/pdmaker/gen/H_<영웅>.java`, `I_<아이템>.java` 로 만들어져
게임과 함께 컴파일됩니다. 아이템 **종류**를 근접 무기/투척 무기/갑옷으로 고르면 원본 `MeleeWeapon`/`MissileWeapon`/`Armor` 를 상속하므로
강화·마법 부여·저주가 그대로 됩니다. "생성될 코드 보기"로 결과를 미리 볼 수 있고, 컴파일 오류는 출력 창에 에디터의 어느 칸 몇째 줄인지 함께 나옵니다.
훅 목록과 형식은 `DESIGN.md` §3.3.1.
